# Enclosure

v9 is current. Case A (left ankle, Node A) and Case B (right ankle, Node B) are mirror images, but the lids are not interchangeable. See `docs/HANDOFF.md` → 外壳.

Files to add here (still on the Windows machine):

| File | Use |
|---|---|
| `CaseA_v9_left_body.step`, `CaseA_v9_left_lid.step` | Left case, for printing |
| `CaseB_v9_right_body.step`, `CaseB_v9_right_lid.step` | Right case, for printing |
| `*_assembly.step` | Body and lid together, for viewing |
| `CaseB_v9_right_with_feather.step` | Right case with Feather and Wing in place |
| `archive/` | v4–v8. v8 and earlier have left and right swapped in the file names; do not use |

Print in black filament (light PLA passes IR). PETG or printing the lid on its side keeps the snap arms from breaking.
